## Rotina diária (base)

Aplicar em todos os dias do período:

- **Bloco 1 (45 min):** estudo do conteúdo do dia (leitura, vídeo ou material da aula).
- **Bloco 2 (45 min):** prática no código (editar `pet-spa-banho-de-luxo.html` ou criar exercícios).
- **Bloco 3 (15 min):** registro do que foi aprendido na seção *Observações* e commit do dia.
- **Revisão rápida (10 min):** reler as anotações do dia anterior antes de começar.

## Detalhamento por dia

### Quinta, 24/09
- [ ] Atividade: reler o PDF "Welcome to Pet Spa" e abrir a página no navegador, listando as seções que ela contém.
- [ ] Atividade: anotar 5 dúvidas ou pontos que não ficaram claros na Aula 2.
- [ ] Entrega: lista de dúvidas registrada em *Observações*.

### Sexta, 25/09
- [ ] Atividade: estudar HTML semântico (`header`, `nav`, `main`, `section`, `footer`) e conferir como a página do Pet Spa usa cada tag.
- [ ] Atividade: exercício — criar uma nova seção "Depoimentos" na página, apenas com HTML, sem estilo.
- [ ] Entrega: commit com a seção nova.

### Sábado, 26/09
- [ ] Atividade: estudar variáveis CSS (`:root`, `var()`) e o uso de cores e fontes da página.
- [ ] Atividade: exercício — estilizar a seção "Depoimentos" reaproveitando as variáveis já existentes.
- [ ] Entrega: commit com o estilo aplicado.

### Domingo, 27/09
- [ ] Atividade: estudar Flexbox e Grid (alinhamento, `gap`, responsividade com `@media`).
- [ ] Atividade: exercício — testar a página em largura de celular e corrigir o que quebrar.
- [ ] Entrega: página funcionando em telas pequenas, com commit.

### Segunda, 28/09
- [ ] Atividade: revisar Git: `status`, `add`, `commit`, `log`, `diff`, criação de branch e merge.
- [ ] Atividade: exercício — criar uma branch `exercicio-git`, fazer 2 commits nela e mesclar em `main`.
- [ ] Entrega: histórico do repositório com a branch mesclada.

### Terça, 29/09
- [ ] Atividade: estudar boas práticas de prompt para o Claude Code (pedidos claros, contexto, revisão do diff).
- [ ] Atividade: exercício — pedir ao Claude Code uma revisão de acessibilidade da página e aplicar ao menos 2 sugestões.
- [ ] Entrega: commit com as melhorias de acessibilidade.

### Quarta, 30/09
- [ ] Atividade: revisão geral da semana (reler anotações e diffs dos commits).
- [ ] Atividade: autoavaliação — marcar o que ficou dominado e o que ainda precisa de reforço.
- [ ] Entrega: cronograma atualizado com os status e rascunho do plano de outubro em *Observações*.
